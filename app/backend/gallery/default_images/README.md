# Базовые изображения

Положите в эту папку изображения, которые должны появиться в пустой галерее
после первого запуска приложения.

Поддерживаемые форматы: `jpg`, `jpeg`, `png`, `gif`, `webp`.

При запуске команда `python manage.py seed_default_images` создает записи
галереи из этих файлов только в том случае, если в галерее еще нет изображений.

Дополнительные названия и описания можно задать в `manifest.json`:

```json
{
  "my-photo.jpg": {
    "title": "My Photo",
    "description": "Будет показано в галерее после первого запуска."
  }
}
```
